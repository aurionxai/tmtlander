The System

Thirteen capabilities, zero add-on SKUs

Eight capability groups, all shipping in every deployment. One price. No tiers hiding features behind a sales call.

Intake & Screening

  • Ping/post API + pre-ping ownership check
  • DNC · blacklist · dedupe · rule validation — at submit, in milliseconds
  • Hosted public intake forms & bulk upload

Routing & Money

  • Buyer routing, accept / reject / return windows
  • Double-entry ledger: costs, revenue, commissions, reversals
  • Vendor & buyer statements, automatic

Enrichment Engine

  • Vendor pipelines with SLAs, callbacks, cost tracking
  • Human-in-the-loop: PIN worklists + signed one-lead links — a person can complete any async step

Partner Portals

  • Auto-built buyer + vendor portals
  • Dashboards, statements, self-serve API keys, webhook drill-ins, docs
  • White-label ready

AI Operation

  • Assistant on every screen — its own consultant
  • ~90 agent tools (MCP) + agent-to-agent (A2A)
  • Agents don't describe the system. They operate it.

Knowledge & BI

  • Knowledge base / RAG with per-KB access grants
  • Datasets: CSV + live slices, dynamic metrics, export
  • Custom dashboards per audience, rendered inside each portal

Observability

  • System status, alerts, API-failure capture
  • Error drill-ins per source / buyer / vendor
  • Webhook delivery tracking + one-click replay

Reliability Core

  • Crash-proof durable pipeline — nothing is ever dropped
  • Lifecycle state machine, schedules, risk gates
  • Connection pooling + backpressure: overload degrades politely, never down
